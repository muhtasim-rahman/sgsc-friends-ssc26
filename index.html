How to Use

Step-by-step guide to create your SSC-26 batch banner

Full README on GitHub
01

Add Photos

Place all 61 friend photos inside the images/ folder. Name them 01.jpg through 61.jpg. Recommended ratio: 4:3 (landscape). Open index.html in your browser.

02

Set Page Size

Pick a preset (Facebook Banner is default at 1640×624px) or type custom dimensions. Enable the lock icon to maintain aspect ratio while resizing. Canvas auto-fits to your screen.

03

Choose Layout

Select 2-Column for side-by-side, 2-Row for stacked, or Center to place the main image surrounded by all friends. Switch main image position with the Side selector.

04

Swap Main Image

Click any thumbnail in the image grid to make it the featured main image. The previous main photo returns to its correct serial position automatically. Serial order is always maintained.

05

Drag to Resize

Hover over the divider bar between the image grid and the main image. A blue handle appears — drag it left/right (or up/down in 2-row mode) to adjust proportions in real-time.

06

Fine-tune Style

Adjust image gap, divider gap, page margin, grid columns (10×6, 12×5, etc.), and canvas zoom from the sidebar. Use Fit to Screen to reset zoom. All changes are live on the canvas.

07

Export Image

In the Export panel below, choose format (PNG / JPG / WebP) and scale (1x default, up to 8x). Click Download Banner. A progress bar tracks rendering. File downloads with resolution in the filename.

08

Share

Upload the exported file to Facebook as a cover photo or banner, share it in your batch WhatsApp/Messenger group, or print it as a keepsake. Built for SGSC SSC-26 — All Boys!

For best results, serve from a local server (VS Code Live Server, Python http.server) or deploy to GitHub Pages. Running directly from the file system may affect image rendering in exports.
